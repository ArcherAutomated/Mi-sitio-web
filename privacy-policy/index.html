Política de Privacidad

Project Skyscraper es una aplicación de automatización de contenido multimedia desarrollada por Archautomated.

La aplicación puede utilizar servicios y APIs de Google para permitir funciones relacionadas con la gestión y publicación de contenido.

Los datos obtenidos mediante las APIs de Google se utilizan únicamente para proporcionar las funciones solicitadas por el usuario y para operar las funcionalidades de la aplicación.

Project Skyscraper no vende los datos de los usuarios ni los utiliza para publicidad personalizada.

Los datos de Google no se transfieren a terceros para fines distintos de los necesarios para proporcionar las funciones de la aplicación.

El usuario puede revocar en cualquier momento los permisos concedidos a la aplicación desde su cuenta de Google.
