Automatización de Canal Personal - Uploader

Esta aplicación es de uso personal y privado. Se utiliza exclusivamente para automatizar la publicación de contenido en canales de YouTube propios mediante la API de YouTube Data v3.

No se recopila, comparte ni almacena información de terceros.

Política de Privacidad

Esta aplicación accede únicamente a los canales de YouTube de su propietario para subir videos de forma automatizada. No se recopilan datos personales de ningún usuario externo. El acceso OAuth se usa exclusivamente para autenticar al propietario de los canales.
